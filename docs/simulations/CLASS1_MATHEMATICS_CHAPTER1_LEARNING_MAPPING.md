## 2. Pedagogical Approach for Young Learners (Ages 5–7)

1. **Concrete Observation Before Abstract Symbols:**  
   Children first watch physical manifestations in a familiar Nepalese village setting rather than reading text alone.
2. **Audio-Guided Instruction (Bilingual):**  
   Every prompt includes a speaker button activating native Nepali speech synthesis so pre-readers can listen and interact independently.
3. **No Penalty Experimentation:**  
   Incorrect attempts trigger soft, supportive verbal coaching ("फेरि प्रयास गर्नुहोस्!") and visual cues rather than harsh deductions.
4. **Multi-Sensory Reinforcement:**  
   Visual 3D motion + audio narration + auditory chime feedback + touch drag-and-drop.
