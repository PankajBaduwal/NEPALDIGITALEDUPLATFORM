- **Textbook:** मेरो गणित, कक्षा १ (२०७६) – Curriculum Development Centre (CDC), Sanothimi, Bhaktapur, Nepal.

## 3. Bilingual Terminology Reference

| English Term | Nepali Term | Spoken Pronunciation | Pedagogical Meaning |
|---|---|---|---|
| **Zero** | **शून्य** | Shunya | Count representing absence of objects |
| **Empty** | **खाली** | Khaali | Containing no objects |
| **No objects** | **कुनै वस्तु छैन** | Kunai vastu chhaina | Zero count in collection |
| **Basket** | **टोकरी** | Tokari | Container holding countable items |
| **Birds** | **चराहरू** | Charaharu | Countable living entities on trees |
| **Ducks** | **हाँसहरू** | Haansharu | Countable living entities in pond |
| **How many?** | **कति वटा?** | Kati wata? | Inquiry prompting quantity counting |
| **Remaining** | **बाँकी** | Baanki | Objects left after departure |
| **Numeral 0** | **सङ्ख्या ०** | Sankhya Shunya | The mathematical glyph for zero |

## 4. Assessment & Mastery Indicators
- Child recognizes that an empty basket contains $0$ apples without hesitation.
- Child tracks that removing the last object from a set leaves $0$.
- Child distinguishes between sets with $1$ item and sets with $0$ items.
- Child associates the Devanagari glyph `०` and English glyph `0` with the concept "empty / none".
