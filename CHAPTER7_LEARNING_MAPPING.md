- **Textbook:** मेरो गणित, कक्षा १ (२०७६) – Curriculum Development Centre (CDC), Sanothimi, Bhaktapur, Nepal.

## 3. Bilingual Terminology Reference

| English Term | Nepali Term | Spoken Pronunciation | Pedagogical Meaning |
|---|---|---|---|
| **Addition** | **जोड** | Jod | The mathematical operation of combining groups |
| **Add / Combine** | **जोड्नु / मिसाउनु** | Jodnu / Misaunu | Putting two groups together |
| **Plus Sign (+)** | **जोड चिन्ह (+)** | Jod Chinha | Symbol representing the addition operation |
| **Equals Sign (=)** | **बराबर चिन्ह (=)** | Barabar Chinha | Symbol indicating numerical equivalence |
| **Total / Sum** | **जम्मा / योगफल** | Jamma / Yogaphala | The resulting count after combination |
| **Altogether** | **जम्मा गर्दा** | Jamma Garda | Combining everything in the set |
| **Count On** | **गनेर जोड** | Ganera Jod | Continuing count forward from first number |
| **Number House** | **सङ्ख्याको घर** | Sankhyako Ghar | Visual structure representing number bonds |
| **Empty Group (Zero)** | **खाली समूह (शून्य)** | Khaali Samuha (Shunya) | Set with no objects; $A + 0 = A$ |

## 4. Assessment & Mastery Indicators
- Child recognizes that putting 2 objects and 3 objects together results in 5 objects.
- Child accurately associates the plus symbol (`+`) with combining and the equals symbol (`=`) with the result.
- Child solves addition with zero ($4 + 0 = 4, 0 + 3 = 3$) without confusion.
- Child can use the counting-on strategy starting at a number rather than recounting from 1.
- Child identifies combinations that make 5 and 10.
